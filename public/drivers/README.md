# Driver portraits (generated)

Nothing here is written by hand. `npm run drivers:normalise` crops these from
the full-body originals in [`assets/drivers/`](../../assets/drivers/) — that is
where images are added, and where the instructions live.

The output is committed, because the deploy builds from the repository and does
not run the importer.

Without a portrait a driver renders their initials on the team's livery colour.
That is a real state, not a broken one: these get filled in a few at a time,
and the layout is identical either way.
